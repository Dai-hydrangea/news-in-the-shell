このツールについて

News In The Shell は、 RSS フィードのキーワードを 3D 多球儀で観測するブラウザ単体ツールです。 本ツール自体はニュースコンテンツを一切配信せず、 ユーザーが指定した RSS フィードをブラウザ内で直接取得・可視化します。

本ツールは RSS リーダーの一種 です。 ニュースキュレーション・配信プラットフォームではありません。 Inoreader / Reeder などと同じ位置付けで、 ユーザーが自ら選んだ feed を閲覧する道具を提供しています。

著作権について

  • 各記事のタイトル・要約・本文・画像の著作権は、 各配信元 (元のニュースサイト) に帰属します。
  • 本ツールは記事タイトルと短い要約 (200 文字以下) のみを表示し、 本文は配信していません。
  • 記事を読むには OPEN ARTICLE → から元サイトへアクセスしてください。 元サイトの利用規約に従って閲覧してください。
  • RSS フィード自体の取得・表示は、 RSS の仕様上意図された使い方であり、 配信元から表示・利用することが許諾されています。

削除・変更依頼について

本ツールは ユーザー側で feed を追加・削除する仕組みです。 特定の feed を本ツールから利用しないよう望まれる場合は、 GitHub Issue にてご連絡ください: GitHub Issues

サンプル feed のリストから特定の feed を外す対応は迅速に行います。 ユーザー個人の localStorage に保存された feed については、 ユーザー自身が SETTINGS から削除できます。

個人情報・データ収集について

  • 本ツールは ユーザーの個人情報を一切収集しません。
  • 追加された feed URL・proxy URL は、 ブラウザの localStorage にのみ保存され、 サーバーには送信されません。
  • RSS フィードへのリクエストは、 ユーザーが設定した CORS proxy 経由でブラウザから直接行われます。
  • 分析ツール (Google Analytics 等) も搭載していません。

CORS Proxy について

ブラウザのセキュリティ仕様 (CORS) により、 多くの RSS フィードはブラウザから直接取得できません。 そのため小規模な中継サーバ (CORS proxy) が必要になります。

推奨: 自前で Cloudflare Worker proxy を立てる。 リポジトリの proxy/ フォルダに完全なコードと 5 分セットアップ手順があります。 Cloudflare の無料枠 (1日 10 万リクエスト) で個人利用には充分。

公開 proxy (corsproxy.io 等) も使えますが、 第三者運営なのでログ収集の可能性とレート制限があります。
