# 使い方 ─ News In The Shell

## 1. 起動

<https://dai-hydrangea.github.io/news-in-the-shell/> を開くだけ。

初回は Welcome モーダルが出ます。 「UNDERSTOOD ─ OPEN SETTINGS」 で SETTINGS が自動で開きます。

## 2. RSS フィードを追加

### ワンクリック追加 (サンプル)

「SAMPLE FEEDS」 の下のチップから、 ボタンを押すだけ:

- **Hacker News** ─ 開発者向け話題 (英)
- **arXiv cs.AI** ─ AI 系学術論文 (英)
- **Wikinews JA / EN** ─ ボランティアによる Wikipedia 系ニュース (日/英、 CC-BY)
- **Lobsters** ─ Hacker News 系の小規模コミュニティ (英)
- **BBC World** ─ BBC のワールドニュース (英)
- **NHK 主要** ─ NHK 主要ニュース (日)
- **GIGAZINE** ─ テック話題 (日)

### 任意の RSS URL を追加

- **NAME**: 表示名 (例: `日経テクノロジー`)
- **URL**: RSS / Atom フィードの URL
- **CATEGORY** (任意): 同じカテゴリの feed は同じ球に入る (例: `tech`)。 空白なら独立した球になる

「+ ADD」 で追加。

### カテゴリの考え方

球の数 = カテゴリの数 です。

- カテゴリ全部空白 → feed ごとに 1 球
- 全部同じカテゴリ → 全 feed が 1 球に集約
- 5 種類のカテゴリ → 5 球

CATEGORY タブとSOURCE タブの 2 ビューで切り替えできるので、 「カテゴリでざっくり」 「ソース別で詳細」 の両方を観測できます。

## 3. CORS Proxy の設定

ブラウザのセキュリティ仕様により、 多くの RSS は直接取得できません。 中継サーバ (proxy) が必要です。

### 方法 A: 公開 proxy を使う (お試し向け)

デフォルトで `https://corsproxy.io/?` が入っています。 そのまま使えますが:
- レート制限が厳しい (頻繁に 429 エラー)
- 第三者運営なのでログ収集の可能性
- 突然停止する可能性

### 方法 B: 自前 Cloudflare Worker (推奨)

5 分で立てられて、 無料枠で個人利用には充分。 [proxy/README.md](../proxy/README.md) 参照。

立てたら `https://your-worker.workers.dev/?url=` を SETTINGS の CORS PROXY URL 欄に貼って 「SAVE & RELOAD」。

## 4. 操作方法

### マウス / トラックパッド

- **◀ ▶ ボタン**: 球を切り替え (リボルバー回転)
- **キーワードクリック**: その語を含む記事一覧が右からスライドイン
- **主役球をドラッグ**: 球を回転 (NewsGlobe スタイル)
- **背景をドラッグ (左右大きく)**: リボルバー回転
- **衛星球をクリック**: その球が中央へ
- **ホイール**: ズーム

### キーボード

- **←** / **→** : 球を切り替え
- **ESC** : モーダルを閉じる

### スマホ / タブレット

- 主役球を指でドラッグ → 球が回転
- 背景を左右にスワイプ → リボルバー回転
- キーワードをタップ → 記事一覧
- ピンチ → ズーム

## 5. リフレッシュ

- 起動時に自動取得
- 30 分ごとに自動再取得
- 右上の **⟳ REFRESH** ボタンで手動再取得

## 6. データの保存場所

- フィードリスト: ブラウザの localStorage
- proxy URL: ブラウザの localStorage
- 記事データ: メモリのみ (タブを閉じると消える、 次回起動時に再取得)

別の端末で同じ設定を使いたい場合は、 SETTINGS の内容を手動でコピー&ペーストしてください。 (将来的に export/import 機能を追加予定)

## トラブルシューティング

### 「FAIL ○○」 と出る

- proxy URL が間違っている → SETTINGS で確認
- 元の RSS URL が間違っている → ブラウザで直接開いて XML が表示されるか確認
- 元サイトが落ちている → 時間をおいて再試行

### 球が表示されない

- フィードを 1 つも追加していない → SETTINGS から追加
- すべての feed の取得に失敗している → ブラウザの開発者ツールでエラーを確認

### キーワードが少ない / 偏っている

- 追加した feed の記事数が少ない → 別の feed を追加
- 短い英単語などは stop words で除外している → ソースコードの `STOP_WORDS` を編集 (fork する)
