## 【無料部分】

### タイトル候補

(本人選択)

A. **News In The Shell ─ ブラウザだけで動く、 自分のためのニュースまとめサイトを作った**

### サムネイル下のリード

昨今の流行りに乗って、Claude Codeを使ってアプリやソフトを作るのにハマっている。
そんな中で「ニュースを攻殻機動隊っぽく見せれるツール作れないかなぁ」とぼんやり考えていた。
AIに相談したところ、意外と行けそうな回答だったので、ブラウザだけで動くツールとして作って公開することにした。

```
NEWS IN THE SHELL
https://dai-hydrangea.github.io/news-in-the-shell/
```

なんでこの形になったのか、 どう動くのか、 何が変わったか ─ 書いておく。

### これは何か

RSS フィードをいくつか登録すると、 その全タイトルからキーワードを抽出して、 3D 球上に表示する。
3D 球は カテゴリごとに分かれていて、 リボルバーみたいに ◀ ▶ で次々切り替わる。

(動画 / GIF をここに貼る)

主役球の上のキーワードをタップすると、 そのキーワードを含む記事一覧が右からスライドで現れて、 クリックで元記事に飛ぶ。 アプリ内に記事を抱え込まない、 元サイトへ誘導するだけ。

「ニュースアプリ」 と呼ぶには情報密度が薄いし、 「アグリゲーター」 と呼ぶには大量配信していない。 自分にとっては **RSS のまとめサイト** という位置付け。

### 動作要件

- ブラウザだけ (Chrome / Safari / Edge / Firefox 全部 OK)
- iPad / iPhone のフルスクリーンブラウザでも快適
- バックエンドは ない。 サーバーレス。 個人情報は一切送信しない。
- (例外: ブラウザの CORS 制約で RSS を直接取れないので、 小さい中継サーバが必要。 5 分で立てる手順は本文で書く。)

### なぜ作ったか

きっかけは 2 つ。

**1 つめ**: ニュースアプリってみんなのおすすめ記事とかがトップに出てきたり、自分の興味ある記事がドンと出てくる。
でも、フラットに観たときにどんなニュースが今流れているかを観たくなった。
（まぁ、でもよく読まれる記事の数が多いので、結局みんなが見ている記事が大きく出るのだけど。）

**2 つめ**: 数ヶ月前に NewsGlobe という、 NHK 政治ニュースだけを見る私的な可視化ツールを作った。 これが自分で作ったのにしてはかなり綺麗に動いて楽しかった。
「これは、好きだったアニメの攻殻機動隊で、ネット上の情報が表示されるような雰囲気が作れるかも・・？」と色気が出てきた。

というわけで、AI君と一緒に議論を進めながら作ったのが、このNews In The Shell。
ちなみに私はコードを１行も書いていない。出てきた結果にあーでもない、こうでもない、あれはできるの？と言うだけだった。

### 設計思想

このツールは、 ニュースを **読ませない** 設計にしている。

- タイトルとキーワードしか出さない
- 記事本文は元サイトに行かないと読めない
- 1 つのキーワードに集約された記事群を見て、 「あぁ、 今は こういうのが多いんだな」 が第一印象で伝わる。

### 3 通りの使い方

このツールは３つの使い方を想定している。
以下の A のようにただ使って楽しんでもらって良いし、興味を持った人は B でダウンロード、 C で fork して自分なりに作り替えてみてほしい。
GeminiやClaude Codeを使えば、コードが書けなくても結構自分好みに直してくれると思う。
陶芸家や書道家が自分で使う道具を自分で作るように、ニュースを自分好みに見れるようになったらかっこいいと思うのだ。

**A. 私の URL を開くだけ (5 秒)**
<https://dai-hydrangea.github.io/news-in-the-shell/> を踏むだけ。 セットアップなし。 私の Cloudflare Worker が proxy を肩代わりするので、 何もせず動く。

**B. ダウンロードしてローカルで動かす (1 分)**
GitHub から ZIP / git clone → `python3 -m http.server` で開く。 アプリは自分の Mac の中で完結。 私の URL に依存しない使い方。

**C. fork して自分の道具にする (15 分)**
GitHub の Fork ボタン → Settings で Pages を有効化 → 自分の URL で運用。 完全に自分のもの。 世界で一つの自分だけの道具になる。

### みんなで面白いものを作ろう！

このツールは、 私と Claude Code (AI) で 1 セッションで作ってます。

つまり、 同じやり方で **あなたも自分の道具を作れる** ということ。 fork して 「ここをこうしたい」 と AI に言えば、 たいてい動くものが返ってくる。 これが個人開発 + AI の現在地。

「こんなアプリ自分でもすぐ作れそう」と思える人がどんどん増えたら面白いと思う。AIの進化でしきいは確実に下がってる。 ただ、 一歩踏み出すかどうかで差ができているのだと思う。
このアプリを踏み台にして、みんながもっと面白いアプリを作ったら素敵だし、僕もそれを使ってみたい。
みんなでAIを使い倒して、面白い世の中にできたら素敵だと思うのだ。

## 【100 円本編】

### 名前について

「News In The Shell」 という名前は、 攻殻機動隊 (Ghost in the Shell) からの意図的な引用。 でも一段だけずらしてある。

- **Shell** = ブラウザという shell
- **Shell** = 攻殻機動隊の Shell (殻、 義体、 容れ物)
- **Shell** = command shell (開発者文化への ウィンク)

伝わる人には伝わってくれたら嬉しいな。

### 設計判断 1: BYOF (Bring Your Own Feeds)

ニュースアグリゲーター系のツールには、 著作権の地雷がある。 「複数のニュースサイトから自動収集」 という形は、 既存の判例 (読売 vs Digital Alliance) の射程に入りやすい。

これを設計で完全に避けるために、 **デフォルトで 0 件の feed** から始めるようにした。 ユーザーが SETTINGS から自分で feed を追加するまで、 ツールは何も見ていない。

これは法的には Reeder や Inoreader と同じ位置付け。 RSS リーダーであって、 ニュースキュレーターではない。 「中身を持たない殻」 として位置付ける。

### 設計判断 2: 球の数を ユーザーに合わせる

最初は 「政治・経済・テック」 みたいなカテゴリを固定しようとしていた。 でも公開版で固定すると、 「政治の球は欲しいけど、 スポーツはいらない」 みたいな個別需要を全部捨てることになる。

なので、 球は ユーザーが追加した feed のカテゴリで自動的に増減する。

- カテゴリを全部 `tech` にすれば 1 球
- 5 つのカテゴリを使えば 5 球
- カテゴリ空白なら feed ごとに 1 球

リボルバーの slot は `buildSlots(count)` で 動的に生成する形にしてあるので、 何個でも対応する。

### 設計判断 3: ブラウザ完結

サーバーは持たない。 これは:
- 個人情報を絶対に集めない (集める場所がない)
- メンテコストゼロ
- ユーザーが安心して使える (ローカルだけで完結)

ただし RSS フィードへのリクエストだけは ブラウザの CORS 制約で proxy が必要。 これだけは仕方ない。

### Cloudflare Worker proxy の立て方 (5 分)

CORS proxy を自前で立てる手順。 GitHub repo の `proxy/worker.js` を Cloudflare Workers に貼って Deploy するだけ。

1. Cloudflare アカウント作成 (無料)
2. Workers & Pages → Create Worker
3. テンプレ名 → Deploy
4. Edit code → 全消去 → `worker.js` 貼り付け → Save and deploy
5. 払い出された URL を SETTINGS に登録、 末尾に `?url=` を付ける

これで 1 日 10 万リクエストまで無料。 個人利用には 100 倍くらい余裕がある。

なぜ自前を勧めるかというと、 公開 proxy (corsproxy.io 等) は:
- レート制限が厳しい
- 第三者運営なのでログ収集の可能性
- 突然停止するリスク

があるから。 本気で使うなら 5 分かけて自前で立てたほうがいい。

### 開発の裏話: NewsGlobe → NetScope → News In The Shell

実はこのツールは いきなりここに来たわけじゃない。 3 段階の進化がある。

**Phase 1: NewsGlobe (2026-03)**
最初は NHK 政治ニュースだけを 1 つの球の上に並べる Python ツール。 完全に自分用、 公開もしてない。 でも 「キーワードを 3D 球面に並べる」 という核アイデアはここで生まれた。

**Phase 2: NetScope (2026-05)**
複数の RSS を取得して、 多球儀化したバージョン。 リボルバー UI もここで完成。 これも自分用 + 父用で、 GitHub Pages に置いて家族で見る程度。 著作権的にもグレー (個人 + 家族の私的複製の範囲)。

**Phase 3: News In The Shell (2026-05、 本記事)**
NetScope の公開版。 BYOF 化、 ハードコード feed 全削除、 法的にクリアにする設計。

進化の方向性は、 全部 「外に置けないものを、 外に置けるようにする」 という調整。 中身を抜いていって、 殻だけにする工程。

### 思想: 「中空構造のツール」

このツールには、 中央に固定された 「正しいニュース」 がない。 おすすめ feed もデフォルトで設定しない。 アルゴリズムも 「人気記事」 を判定しない。

ただ、 ユーザーが選んだ RSS の単語が並んでいるだけ。

これは 河合隼雄が日本文化の特徴として論じた **中空構造** に近い設計判断。 中心が空洞だから、 ユーザーが自由に動ける余地ができる。

(技術書 ではなく 中身が柔らかいので、 哲学に興味なければスキップしてください。)

### 自分にとってのこのツールの位置

ニュースは読みに行かないと中々興味ない領域は見に行かない。でも、これをスクリーンセーバーみたいにパソコンの画面に流しておくと、なんとなく「今 こういうキーワードが集中している」 という地形だけ見えてくる。

それに、ちょっとカッコいい。いつもの日常がSFみたいだ。
もし、同じセンスの人がいたら、 ぜひ試してみてほしい。ちょっとかっこいいぞ。
